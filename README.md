# All the damage types
Adds a lot of damage types and variants of each bullet/rocket/laser turret/etc. for each of the damage types and scrambles enemies' resistances

Made for Foundry Production Jam "Analysis Paralysis"

Suggestions for new damage types are welcome!

# Compatibility
Do NOT install on existing savefiles - enemies will likely be immune to your defenses and asteroids will wreck your spaceships

Should be generally compatibe with mods adding enemies/ammo/weapons

## Special notes:
[Rampant Fixed](https://mods.factorio.com/mod/RampantFixed) - works, but resistance scrambling functionality gets overriden by rampant
